# GPU Profiling Baseline — pre-optimization
# GPU: NVIDIA GeForce RTX 2050 (4GB, compute 8.6)
# Config: N=1000, Verlet, 10 steps, dt=0.01

## forces_kernel_tiled (dominates: ~5 ms per invocation)
- SM throughput: 22.36%
- FP64 pipeline: 89.5% utilization (compute bottleneck)
- Achieved occupancy: 16.7% (theoretical 83.3%)
- Grid: 4 blocks / 16 SMs → 12 SMs idle
- Top CPI stall: MIO (shared memory) 91.7%
- FP instructions: 544K fused + 384K non-fused (21% improvable)
- DRAM throughput: ~5.9 GB/s

## integr_verlet_pos_kernel (~7 μs)
- SM throughput: 8.76%
- FP64: 49.5%
- Achieved occupancy: 15.5%
- Top stall: MIO 42.5%, L1TEX 35.5%

## integr_verlet_vel_kernel (~6 μs)
- SM throughput: 6.22%
- FP64: 36.9%
- Achieved occupancy: 15.3%
- Top stall: L1TEX 49.1%

## Key optimization targets
1. Grid underutilization for small N (4 blocks / 16 SMs)
2. FP64 compute bound (89.5%) — consider mixed precision in future
3. Shared memory stalls (91.7% CPI)
4. 11 redundant cudaDeviceSynchronize calls
5. D2D copies in Verlet (3/step) and RK4 (48/step)
6. Host arrays use malloc() not cudaMallocHost()
7. No constant memory for G/SOFTENING
8. No __restrict__ or __launch_bounds__

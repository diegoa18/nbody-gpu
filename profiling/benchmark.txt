## 4. Observaciones
- Crossover GPU direct vs CPU direct: ~N=800
- Crossover GPU BH vs GPU direct: ~N=2000
- GPU BH vs GPU direct speedup a N=100000: 26.99x
- GPU BH vs CPU BH speedup a N=100000: 4.32x
- GPU BH memory-bound a N pequeños (overhead de construcción del octree)
- GPU BH compute-bound a N grandes (tree-walk domina)
